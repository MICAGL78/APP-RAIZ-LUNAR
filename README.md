# Raíz Lunar

Aplicación web instalable (PWA) para la huerta, con recomendaciones diarias, meteorología, calendario lunar, labores regenerativas y registro de plantaciones y frutales.

## Despliegue

Este repositorio se vinculará al proyecto Netlify **raiz-lunar** existente. Rama de producción: `main`. Directorio de publicación: `.`. Sin comando de compilación.

La app conserva los registros locales en el navegador. Las notificaciones push remotas y el análisis fotográfico con IA requieren integración adicional.
